# Sentiment Analysis Web Application

A Python-based sentiment analysis web application that analyzes user-provided text and classifies it as **positive, negative, or neutral** along with a confidence score.

This project was developed as part of an IBM Skills Network project and extended through implementation of the sentiment analysis service integration, Flask application logic, unit testing, packaging, and error handling.

## Features

* Analyzes text for positive, negative, or neutral sentiment
* Integrates with the IBM Watson NLP sentiment analysis service
* Displays the sentiment label and confidence score
* Handles invalid or unsupported inputs gracefully
* Includes unit tests for positive, negative, and neutral inputs
* Provides a simple web interface for entering text

## Technologies Used

* Python
* Flask
* REST APIs
* IBM Watson NLP
* Requests
* Python `unittest`
* HTML
* JavaScript

Running the Application

Install the required Python packages:

pip install flask requests

Start the Flask application:

python3 server.py

Then open the application using the local Flask server.
